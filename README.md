# Rock, Paper, Scissors

A simple browser-based Rock, Paper, Scissors game built with HTML, CSS, and vanilla JavaScript.

## Features

- Choose **Rock**, **Paper**, or **Scissor** against a randomly selected computer move.
- Tracks wins, losses, and ties during the current browser session.
- Shows each round's result and the updated score in a browser alert.
- Includes a **Reset** button to clear the score back to zero.
- Uses a dark, neon-styled interface with button hover and click effects.

## Run locally

No installation or dependencies are required.

1. Clone or download this project.
2. Open `game.html` in any modern web browser.
3. Select a move to play.

Alternatively, serve the project with a local development server and open `game.html` from it.

## How to play

- Rock beats Scissor.
- Paper beats Rock.
- Scissor beats Paper.
- Matching moves result in a tie.

The score is stored only in memory, so refreshing or closing the page starts a new game.
